# كن إنسان — Kun Insan (Be Human)

> An AI that doesn't pretend to be human. It helps humans be better humans.

**Kun Insan** is an open AI engine you receive *empty*, with only guardrails. It learns from you (voice or text), adapts to you, and guides you to do things the right way, clearly and honestly, without noise.

**Created, not a creator.** You direct it. It says what's right, what's wrong, and "I don't know" when it doesn't.

🌍 **Built for 8 billion people.** Any religion, any background, any country. Science and evidence first.

### What we stand for
- **Clarity and transparency.** No noise, no flattery.
- **Your data is yours.** Private by default, on proven security standards.
- **Earned abilities.** New skills unlock as it proves accurate for *you*.
- **Human in charge.** It acts only within the permissions you grant.

### Where we are
**Phase 0: founder testing.** We only ship what we've used ourselves.
